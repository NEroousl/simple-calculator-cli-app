# Basic Calculator Application

A fully functional, command-line based Basic Calculator developed in Python. This tool allows users to perform basic arithmetic operations, maintains a session history of calculations, and provides a clean, user-friendly interface.

## Developer
**Malinda Vitharana**

## Features
- Addition, Subtraction, Multiplication, and Division
- Keep track of operations via the Calculation History feature
- Elegant Command-Line Interface (CLI)
- Error handling (e.g., Division by Zero)

## Requirements
- Python 3.11 or above.

## How to Run
```cmd
python calculator_app.py
```

## How to Test
```cmd
python -m unittest test_calculator.py
```
